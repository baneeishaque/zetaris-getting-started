# Redacted opencode session logs

This directory is a redacted copy of `.opencode/logs/`. Values for
`ZETARIS_ADMIN_PASSWORD`, `ZETARIS_PASSWORD`, and `ZETARIS_API_KEY`,
plus other detected credential patterns, are replaced with
`[REDACTED]`.

The raw logs remain local and untracked. This copy is committed as
session evidence only; it is not a runnable configuration.
